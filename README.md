# Project ASTRO

**Assistive Systems for Trusted Robotic Operations**

Project ASTRO is a solo, one-year research build led by Faisal Farouq. It explores whether a friendly human-support robot can be developed through staged software, benchtop, single-leg and tethered whole-body demonstrations.

The project keeps people in control. Year-one work excludes clinical use, real patient data, person lifting, unsupervised motion and unreviewed powered testing. Physical milestones remain blocked until their documented engineering, facility and safety prerequisites are satisfied.
