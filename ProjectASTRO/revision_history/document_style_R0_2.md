# Project ASTRO document style

Revision R0.3 | 2026-11-08 | Owner Faisal Farouq

Project documents use a restrained academic engineering style based on the supplied E7 reference PDF.

- Use US Letter pages with generous margins and a white background.
- Use a classic serif typeface for titles, headings and body text.
- Center the main document title. Keep section headings bold and left aligned.
- Use black text, thin black rules, light table borders and no decorative color blocks.
- Use a small centered running header and a centered page number on later pages when pagination helps navigation.
- Give forms, calculations and review fields clear ruled boxes with comfortable internal spacing.
- Keep tables compact, readable and aligned. Use bold column headings and repeated headers on continued pages.
- Use monospaced type only for code, identifiers and file paths.
- Keep numbers, units, evidence references and status labels explicit.
- Keep CSV and JSON structurally plain. Apply the visual system to their readable companion documents.
- Use Project ASTRO and the expansion Assistive Systems for Trusted Robotic Operations in public-facing documents.
- Do not include tool attribution, AI-assistance statements or internal authoring notes in project deliverables.

The robot's established physical concept remains unchanged. The document design does not imply institutional, clinical or third-party endorsement.
